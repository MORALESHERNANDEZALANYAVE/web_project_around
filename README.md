# Tripleten web_project_around

## Descripción del Proyecto

Es una página interactiva para conocer algunos de los lugares de los que proceden los colegas de TripleTen. El proyecto permite editar la información del perfil, agregar tarjetas con imágenes, dar «Me gusta», eliminar tarjetas y abrir imágenes en ventanas emergentes.

El diseño es adaptable a diferentes tamaños de pantalla y utiliza la metodología BEM para organizar los estilos y archivos del proyecto.

## Tecnologías y Técnicas Utilizadas

- **HTML5**: Estructura del contenido y formularios.
- **CSS3**: Diseño adaptable mediante media queries, fuentes personalizadas con @font-face y metodología BEM.
- **JavaScript ES6**: Programación orientada a objetos mediante las clases Card y FormValidator, módulos con import y export, manipulación del DOM y validación de formularios.

- **Git y GitHub**: Control de versiones y publicación del proyecto.
